# Irrigation Replicator Reproducibility

Code and scenario parameters for reproducing the calculations and figures of a three-strategy replicator-dynamics model of irrigation technology adoption. The model compares gravity, pressurized, and computerized irrigation strategies through crop yields, production costs, and market conditions.

## Requirements

- Python 3.12.
- For the two LaTeX diagrams: a working pdfLaTeX installation with `standalone`, TikZ/PGF, PGFPlots 1.18, `graphicx`, `setspace`, `microtype`, and Times fonts. TeX Live's pictures, latex-extra, and recommended-fonts collections provide these packages.

Two Python environments preserve the plotting versions used for the figures. The main environment uses Matplotlib 3.10.8; the slice figures use Matplotlib 3.11.1. The dependency files specify both environments.

## Installation

Download and extract the repository, or clone it. Open a terminal in the directory containing `run.py`, then run:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
python3 -m venv .venv-slices
.venv-slices/bin/python -m pip install -r requirements-slices.txt
```

On Windows, use `py -3.12` instead of `python3`, and replace each `bin/python` with `Scripts/python.exe`.

## Run

Generate the calculations and all executable figures:

```sh
.venv/bin/python run.py --slice-python .venv-slices/bin/python
```

Generate the calculations and numerical figures without requiring LaTeX:

```sh
.venv/bin/python run.py --slice-python .venv-slices/bin/python --numerical-only
```

The workflow writes calculated tables to `output/tables/`, comparative-statics figures to `output/`, and grouped phase-plane figures to `output/replicator_phaseplane/`. Outputs are generated when the code runs.

## Contents

| Path | Purpose |
|---|---|
| `run.py` | Entry point |
| `code/` | Analytical calculations and figure-generation code |
| `data/scenarios.csv` | Scenario parameters |
| `requirements.txt` | Main Python dependencies |
| `requirements-slices.txt` | Slice-figure Python dependencies |

The study-area map is not generated by this workflow.
